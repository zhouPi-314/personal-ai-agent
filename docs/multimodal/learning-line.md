# 学习线（M1.5）：从聊天里学表情包

> 批准：2026-10-24（用户：批准 M1.5；策略"先攒着，不学太快"）
> 状态：**已实现**，`PAA_MEDIA_LEARN_ENABLED` 默认关，打开后只收不自动入库。

## 1. 要解决什么

Fluent Emoji 是"通用表情"，不是"我的表情"。学习线让素材库从**你自己的聊天**里长出来：
你发过的图会被收进隔离区，等你一句话确认后进入素材库，之后在对的场景里发回给你。

**不训练模型**：这是"统计 + 检索"，不是梯度下降。好处是可解释、可回滚、零算力。

## 2. 数据流

```text
你在私聊发一张图/表情
  -> OneBot image / mface 段 -> MediaRef（只描述位置）
  -> MediaFetcher 校验：协议白名单、私网拦截、≤2MB、真实 MIME、随机文件名
  -> 隔离区 data/media/quarantine/（pending）
  -> 标签猜测：用"你发图前那句话"的情绪词（intent_for）
  -> 人工确认：promote（可改标签）/ reject
  -> 晋级：移入 data/stickers/<tag>/ + 追加 index.json（license=owner-provided）
  -> 之后按原有选图逻辑被发送
```

## 3. 三级状态（对应"先攒着"）

| 状态 | 含义 | 能不能被发出去 |
|---|---|---|
| `pending` | 已收录，等确认 | ❌ |
| `promoted` | 已晋级进素材库 | ✅ |
| `rejected` | 丢弃（文件已删除） | ❌ |

没有"自动晋级"。开关只管"收不收"，不管"能不能用"——这是刻意的。

## 4. 收录规则（谁能进）

| 条件 | 说明 |
|---|---|
| 只私聊 | 群聊一律不收（群图来源不可控） |
| 只主人 | `PAA_OWNER_QQ` 精确匹配，别人的图不进 |
| 非自己发的 | 排除机器人自身回声 |
| 图片类 | JPEG/PNG/GIF/WebP；其他格式直接拒绝 |
| ≤2MB | 超限不下载（流式读到上限即中止） |
| 总量与频次 | 默认每天 10 张、累计 200 张 |
| 去重 | 同 sha256 只留一份 |

## 5. 标签怎么来

1. **首选**：收录时用你上一条文字的情绪词猜（`哈哈哈`→开心、`气死`→生气）。
2. **兜底**：猜不到就留空，晋级时必须 `--tag` 指定，避免乱贴标签。
3. **纠正**：晋级时 `--tag` 覆盖猜测，纠正结果直接写进素材库索引。

## 6. 操作手册

```powershell
# 看收了多少、待确认几条
.\\.venv\\Scripts\\python.exe scripts\\sticker_learn.py stats

# 列待确认（显示 sha 前 8 位、体积、猜到的标签、时间）
.\\.venv\\Scripts\\python.exe scripts\\sticker_learn.py list

# 晋级（不写 --tag 就用猜到的标签）
.\\.venv\\Scripts\\python.exe scripts\\sticker_learn.py promote 8af20fb0 --tag 开心

# 丢弃
.\\.venv\\Scripts\\python.exe scripts\\sticker_learn.py reject 8af20fb0
```

## 7. 安全与隐私红线

1. 图上文字**永远只当数据**：不 OCR 进提示词、不影响权限判定、不改人设。
2. 只学主人自己发的；别人的图不下载、不落盘。
3. 全部落在 `data/`（`.gitignore` 已排除），**不进 Git、不上传**。
4. 可按 sha256 单张删除；删目录即整条学习线清零。
5. 拉取有协议白名单 + 私网/回环拦截 + 大小上限，防 SSRF 与压缩炸弹。
6. 收录失败只记一行 `warning`，**不影响聊天回复**。

## 8. 已知限制

- 标签靠关键词猜测，没有视觉理解；阶段 D 接入视觉后可以自动打标并纠正历史标签。
- 没有"使用频次加权"：暂时不统计"这个场景你更爱用哪张"（等有足够样本再做，D39）。
- 晋级是纯手工；样本稳定后再考虑"白名单自动晋级"。
- 只处理图片；QQ 的 `face`（小黄脸）没有图片实体，学不了。
- 学习线目前**不参与**选图打分，晋级后和其他素材等价。
